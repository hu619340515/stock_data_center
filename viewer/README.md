# 📊 Stock Data Center — 可视化管理界面

> `viewer/server.py` 提供基于 Flask 的 Web 可视化管理服务，支持数据浏览、图表分析、数据导出与数据库管理四大功能模块。

---

## 🚀 快速启动

```bash
# 在项目根目录执行
python viewer/server.py

# 或指定自定义数据库路径
DB_PATH=/path/to/quant_data.db python viewer/server.py
```

启动后访问：**http://localhost:5678/**

---

## 🗂 目录结构

```
viewer/
├── server.py        # Flask 后端服务（路由 + 数据库读取 + API）
├── db_portrait.md   # 数据库表结构说明文档
└── README.md        # 本文件
```

> 前端页面（`index.html`）内嵌于 `server.py` 中，通过 `/` 路由直接返回，无需额外静态文件。

---

## 🧩 四大功能模块

### 1. 📋 数据浏览（Data Browser）
- 左侧 **Tab 栏** 列出数据库中所有数据表
- 支持 **关键字搜索**、**字段筛选**、**分页浏览**
- 顶部 **概览卡片** 展示各表总行数、最新更新时间

### 2. 📈 图表可视化（Chart Visualization）
- 自动识别时序数据，绘制 **K 线图 / 折线图 / 柱状图**
- 支持多字段叠加对比（如收盘价 vs 成交量）
- 基于 **ECharts** 渲染，支持缩放、十字准线、数据提示

### 3. 📤 数据导出（Data Export）
- 支持将当前查询结果导出为 **CSV** 文件
- 导出按钮位于表格工具栏右侧

### 4. 🛠 数据库管理（DB Management）
- 展示数据库文件路径、大小、表数量等元信息
- 支持查看每张表的 **建表 SQL**（Schema）
- 提供各表 **行数统计** 与 **字段类型** 一览

## 🔌 API 清单

| 方法 | 路径 | 说明 |
|------|------|------|
| `GET` | `/` | 返回前端 HTML 页面 |
| `GET` | `/favicon.ico` | 返回空 204（消除浏览器报错） |
| `GET` | `/api/tables` | 获取所有表名及行数列表 |
| `GET` | `/api/table/<name>` | 分页查询指定表数据（支持 `page`、`page_size`、`search` 参数） |
| `GET` | `/api/schema/<name>` | 获取指定表的字段定义（列名、类型） |
| `GET` | `/api/chart/<name>` | 获取指定表的图表数据（自动识别时序字段） |
| `GET` | `/api/db_info` | 获取数据库元信息（路径、大小、表数量） |
| `GET` | `/api/export/<name>` | 导出指定表为 CSV 文件下载 |

### 查询参数说明

```
GET /api/table/<name>?page=1&page_size=50&search=keyword
```

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `page` | int | 1 | 当前页码（从 1 开始） |
| `page_size` | int | 50 | 每页行数（最大 500） |
| `search` | str | — | 全字段模糊搜索关键字 |

## 🗄 数据库说明

- **默认路径**：项目根目录下的 `quant_data.db`
- **自动解析**：启动时自动读取 `config.yaml` 中的 `database.path` 字段
- **环境变量覆盖**：设置 `DB_PATH` 环境变量可覆盖默认路径

包含的主要数据表（详见 [db_portrait.md](db_portrait.md)）：

| 表名 | 说明 |
|------|------|
| `stock_basic` | 股票基本信息（代码、名称、上市日期等） |
| `daily_price` | 日线行情（开高低收、成交量、换手率等） |
| `index_daily` | 指数日线行情 |
| `financial` | 财务数据（净利润、ROE、市盈率等） |
| `holder_num` | 股东人数变化 |
| `money_flow` | 资金流向（主力、超大单净流入等） |
