# Git 提交信息规范

## 提交类型前缀
- `feat:` - 新增功能
- `fix:` - 修复 bug
- `refactor:` - 重构（不改变功能）
- `style:` - 代码格式调整（空格、缩进等）
- `docs:` - 文档更新
- `test:` - 测试相关
- `chore:` - 构建/工具链相关

## 示例格式
```
<type>: <subject>

<body>

<footer>
```

## 股票数据中心项目特有类型
- `data:` - 数据获取/存储相关
- `viewer:` - 前端/查看器相关
- `core:` - 核心逻辑/进程管理
- `db:` - 数据库相关
- `config:` - 配置相关
