### A股量化数据中枢

这是一个基于 **Python + MongoDB + Baostock** 的高性能A股历史数据与实时数据自动化处理系统。

它专为量化交易策略回测和实盘分析设计，实现了从**数据获取**、**清洗**、**存储**到**每日增量更新**的全流程自动化。

#### 核心特性

- **全自动化流水线**：一键执行全量历史数据下载或每日增量更新。
- **高性能流式处理**：摒弃传统的“先存CSV再入库”模式，采用内存流式处理，显著提升效率。
- **MongoDB 最佳实践**：采用统一集合存储设计，配合复合索引，查询性能极佳，避免了“单股单表”的性能陷阱。
- **断点续传与容错**：内置智能重试机制，网络波动不中断；增量更新自动识别最后交易日，避免重复下载。
- **数据清洗**：自动处理数据类型转换、空值填充，确保入库数据质量。

#### ️ 技术栈

- **编程语言**: Python 3.8+
- **数据源**: Baostock (证券宝)
- **数据库**: MongoDB
- **核心库**: `pymongo`, `pandas`, `baostock`, `click`

#### 快速开始

**1. 环境准备**

确保你已经安装了 MongoDB 并且服务正在运行。

**2. 安装依赖**

```
pip install baostock pandas pymongo click
```

**3. 配置修改**

打开 `config.py`，根据你的环境修改配置（通常默认即可）：

```
MONGODB_URI = "mongodb://localhost:27017/"
MAX_WORKERS = 3  # 建议 3-5，Baostock 免费接口有并发限制
```

**4. 运行测试**

在正式全量下载前，建议先运行测试脚本，验证数据库连接和下载流程是否正常：

```
python test.py
```

*该脚本仅处理前10只股票，速度快，用于验证环境。*

**5. 全量/增量更新**

- **全量下载** (首次使用，耗时较长):

```
python cli.py full
```

- **每日增量更新** (日常使用，秒级完成):

```
python cli.py update
```

- **查看状态**:

```
python cli.py status
```

#### 数据库设计

系统使用 MongoDB 存储数据，采用**统一集合**模式。

- **数据库名**: `stock_data`
- **集合名**: `stock_daily`
- **数据结构示例**:

```
{
  "_id": "ObjectId(...)",
  "code": "sh.600000",
  "date": "ISODate('2023-04-11')",
  "open": 10.5,
  "high": 10.8,
  "low": 10.4,
  "close": 10.7,
  "volume": 123456,
  "amount": 123456789,
  ...
}
```

- **索引**: 自动创建 `code` + `date` 的复合唯一索引，确保数据不重复且查询高效。

#### ️ 命令行工具说明

本项目使用 `click` 库封装了友好的命令行接口：

| 命令 | 描述 |
| ------ |------ |
| `python cli.py full` | 启动全量流式下载流水线（从1999年至今） |
| `python cli.py update` | 启动增量更新流水线（仅下载最新数据） |
| `python cli.py status` | 查看当前数据库中的总记录数 |
| `python test.py` | 快速测试流程（仅处理前10只股票） |

#### 优化记录

- **架构重构**: 从分散的脚本整合为模块化包结构，消除了大量重复代码。
- **性能提升**: 引入多线程并发（`ThreadPoolExecutor`）和批量写入（`bulk_write`），速度提升数倍。
- **流式处理**: 移除中间 CSV 文件存储环节，数据直接在内存中流转，节省磁盘 I/O。
- **智能容错**: 针对 Baostock 接口在非交易日或网络波动时的表现进行了专门优化（如自动回退日期、自动重试）。
